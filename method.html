The Re-Charge Method

Seven phases, one number to improve.

Most AI projects fail for boring reasons: the wrong process, data that isn’t ready, nobody measuring, nobody using it. Our method is built to catch each of those before it costs you, and to prove the result after.

The phases

What happens, and what you get at each step.

  1. 01

    Discovery

    We map the people, processes, software, data, bottlenecks, repetitive work and decision points. Then we measure the baseline: how long the work takes today, how often, and what it costs.

    You get: a process map and baseline numbers.

    Discovery
  2. 02

    Opportunity mapping

    Every opportunity we find is scored on six factors and ranked. Some will be quick wins, some need the data fixed first, some aren’t worth it. We say which.

    You get: a scored opportunity map and a recommended first build.

    Discovery
  3. 03

    Proof of concept

    We build the smallest useful version and put it to work on real cases with the people who’ll use it. Not a demo: a working slice.

    You get: a working system on real work.

    Implementation
  4. 04

    ROI validation

    Before vs after, on the same measure. If the number moved, we go to production. If it didn’t, we adjust or stop — and you haven’t paid for a full build that doesn’t work.

    You get: a measured result and a go / adjust / stop decision.

    Implementation
  5. 05

    Production

    We integrate it properly: your real software, permissions, logging, error handling, and a safe fallback for when a model or service misbehaves.

    You get: a production system and its runbook.

    Implementation
  6. 06

    Adoption

    We train the people who use it and adjust the system to how they actually work. A system nobody uses saves nothing.

    You get: a trained team, with usage tracked.

    Implementation
  7. 07

    Optimisation

    We monitor it, test its accuracy, keep it secure, tune the workflow and add integrations as you grow. Every month you get a report that leads with the result.

    You get: a monthly ROI report and a system that improves.

    Operations
Phase 2, in your browser

Score an opportunity.

The same six factors and formula we use in discovery. Score a few of your own ideas and see which one to build first.

0/ 100

    Score = 2.5·Time + 1.5·Revenue + 1.5·Data + 1.5·Adoption + 1.5·(10 − Difficulty) + 1.5·(10 − Risk). Data ≤ 3 means fix the data first; risk ≥ 8 means a person approves every output.

    How we measure ROI

    A baseline first. The same measure after. A report every month.

    We don’t build anything until the number we’re improving is written down, with how it was measured. After go-live we measure it the same way, and that’s the number in your report.

    • Hours saved a month(minutes before − minutes after) × items a month ÷ 60
    • Value of those hourshours × loaded hourly cost (salary × 1.3 ÷ 173, or your own figure)
    • Paybackimplementation ÷ (monthly value − operations fee)
    • Revenue effectsreported separately, and only when measured — never quietly added
